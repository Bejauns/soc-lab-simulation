# SOC Lab Simulation Project

## 📌 Overview
This project simulates a basic Security Operations Center (SOC) environment using tools like Splunk and Wireshark. It focuses on monitoring network traffic, detecting threats, and responding to incidents.

## 🛠 Tools Used
- Splunk (for log analysis and alerting)
- Wireshark (for packet inspection)
- Kali Linux (attacker machine)
- VirtualBox or VMware
- Security Onion (optional)

## 🔍 What I Did
- Set up a virtual lab using VirtualBox with multiple VMs.
- Installed Splunk and configured log sources (e.g., syslog, firewall).
- Ran simulated attacks using Kali Linux (e.g., brute-force SSH).
- Captured traffic and analyzed logs in Splunk.
- Created alerts for suspicious behavior and documented findings.
